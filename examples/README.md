# 示例

三个可直接运行的示例，用于验证安装是否正确，并复现论文方法学部分的关键数字。
前两个不需要波形数据，第三个使用随包附带的 20 条记录。

```bash
python examples/01_forward_cross_validation.py
python examples/02_thickness_from_traveltime.py
python examples/03_inspect_waveforms.py
```

## 01 双路径正演一致性检验

复算平层解析公式与 TauP 变莫霍精确射线追踪的走时敏感度之差。
预期输出（Vp = 6.0 km/s，震源深度 92 km，震中距 55°）：

| 莫霍深度 H (km) | TauP 理论 pP−pmP (s) |
|---|---|
| 8.0 | 2.426 |
| 12.0 | 3.639 |
| 16.0 | 4.852 |
| 20.0 | 6.065 |

TauP 斜率 0.30327 s/km，解析斜率 0.30675 s/km，**相对差异 1.13%**。

首次运行需编译 4 个变莫霍速度模型（约 0.4 s/个），之后走缓存。

## 02 从走时差反演厚度

对一组典型观测（Δt = 4.20 s，震源深度 96.3 km，震中距 55°）给出两条路径的厚度、
网格搜索的置信区间与边界判据，以及误差预算。预期厚度约 14 km，总不确定度约 ±2.1 km。

`at_edge` 为真表示最优解顶在搜索边界，该组结果不可信——这是判断反演是否有效的
关键判据。

## 03 读取随包波形

`examples/data/` 中是 2011-09-03 南桑威奇事件（震源深度 96.3 km）的 20 条 BHZ 记录，
自完整数据集的 266 条中等间隔抽取，震中距 46.99°—94.57°。脚本读取全部记录并逐道
计算射线参数与走时敏感度。

这些数据仅用于让使用者不必下载全量数据即可跑通流程，**不足以复现论文结果**——
论文用了 16 个事件的 2316 条记录。
